# Student Management System

## About Project
A console-based application developed using Java
and MySQL to manage student records.

## Technologies Used
- Java
- JDBC
- MySQL
- MySQL Connector/J

## Features
1. Add Student
2. View Students
3. Search Student
4. Update Student
5. Delete Student
6. Exit

## Database
Database Name: StudentDB
Table Name: Student

## How to Run
1. Install Java JDK.
2. Install MySQL.
3. Create StudentDB database.
4. Download MySQL Connector/J.
5. Compile and run the Java program.
